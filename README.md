# URL-Detection-System 
Uni's Final Year Project

### Project Overview

This project is a Python-based URL Phishing Detection System developed as part of my final-year BSc Computer Science project.

The aim of the system is to identify potentially malicious and phishing URLs by analysing different characteristics of a website's URL. Phishing websites are commonly used by attackers to trick users into sharing sensitive information, such as login credentials and personal details.

The system analyses submitted URLs and predicts whether they are legitimate or potentially phishing using machine learning techniques.

### Project Objectives

The main objectives of this project are:
- Research phishing attacks and understand how malicious URLs are created.
- Identify URL features that can help distinguish phishing websites from legitimate websites.
- Develop a Python-based detection system.
- Implement machine learning techniques to classify URLs.
- Test and evaluate the accuracy and reliability of the system.
- Provide users with a simple way to check potentially suspicious URLs.

### Features

- URL Analysis: Examines submitted URLs for potentially suspicious characteristics.
- Phishing Detection: Predicts whether a URL is legitimate or potentially malicious.
- Machine Learning: Uses machine learning to assist with URL classification.
- User Interface: Provides a straightforward way for users to interact with the system.
- Results: Displays the classification result for each submitted URL.
